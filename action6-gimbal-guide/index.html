ACTION 6 × GIMBAL
図解構成動画チェック
SHOT DESIGN FIELD GUIDE

動かすより、
意図して動かす。

Action 6＋HOHEM iSteady Pro 4のような小型ジンバルで、横スライド／下→上だけに寄らず、映像の語彙を増やすための実戦図解。

基本原則：カメラは止めてよい。動かすときは「何を見せるために動くか」を1カットにつき1つ決める。

まず覚える10種類

湯川内のような木・水・石・柱がある場所は、前景／中景／背景を意識すると特に強い。

01 / LOCKED-OFF

固定ショット

ジンバルを持っていても止める。水・湯気・葉・人だけを動かす。

全景・タイトル・水面は3〜5秒固定。
02 / PUSH / PULL

寄る・引く

移動の終点を先に決める。湧出口や看板など「到着する対象」を作る。

開始1秒静止 → 移動 → 終了2秒静止。
03 / REVEAL

隠して見せる

横スライドを「柱や暖簾で隠す→主題を出す」に変える。

前景で最初は画面の半分以上を隠す。
04 / PARALLAX

パララックス

前景を20〜40cmまで近づけて横移動。近い物ほど速く流れ、奥行きが出る。

木の柱・浴槽の縁・葉を前景に。
05 / ORBIT

回り込み

被写体を見たまま円弧状に歩く。360°ではなく15〜30°で十分。

石灯籠・桶・看板・人物など立体物向き。
06 / TILT REVEAL

意味のある下→上

上下移動は「新しい情報が順に現れる」ときに使う。

木の縁 → 浴槽 → 建物、のように段階を作る。
07 / ANGLE

Low / Top

目線の高さを外す。同じ場所でも水面ギリギリと真上で別の画になる。

Actionカメラは低位置が特に得意。
08 / SHOT SIZE

Wide → Detail

全部が広角になるのを防ぐ。同じ被写体を距離違いで最低3本。

Wide / Medium / Detail / 超寄り。
09 / SUBJECT MOTION

被写体を動かす

カメラ固定で、桶・手・湯気・水滴・人を動かす。

「カメラが動く＝動画」から抜ける。
10 / EDITABLE CLIP

1カット1動作

前進→Tilt→横移動を1本でやらず、動作ごとに分ける。

Resolveで切りやすく、速度変更もしやすい。

湯川内ならこう組む

30秒前後の縦動画を想定。

全景固定 3秒 → 入口/看板 Detail 2秒 → Reveal 3秒 → Push-in 3秒 → 水面固定 2秒 → 湧出口 Detail 2秒 → 木・水滴 Detail 2秒 → Low tracking 3秒 → Parallax 3秒 → Hero固定＋タイトル 4秒 → Pull-away 3秒
